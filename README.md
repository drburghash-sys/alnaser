# NASSR HUB | نصر هَب

تطبيق جماهيري عربي لنادي النصر، مصمم للجوال ويعمل كتطبيق ويب قابل للتثبيت (PWA).

## الموجود حاليًا
- بحث داخل اللاعبين والبطولات والتاريخ
- قاعدة أولية للاعبين والأساطير
- خزانة بطولات قابلة للتوثيق والتوسعة
- خط زمني لتاريخ النادي
- مركز إحصائيات مهيأ لإضافة بيانات الموسم
- تصميم أصفر/أزرق مناسب للنصر
- PWA + وضع Offline أساسي

## تشغيل GitHub Pages
من Settings > Pages اختر **Deploy from a branch** ثم `main` و`/(root)`.

بعد النشر يصبح الرابط:
https://drburghash-sys.github.io/alnaser/


## بنية البيانات
أصبحت المعلومات مفصولة عن الواجهة داخل مجلد `data/`:
- `current-players.json` — لاعبو الفريق الحالي
- `legends.json` — الأساطير والرموز والنجوم التاريخيون
- `seasons.json` — أرشيف المواسم وربط كل موسم بنجومه
- `trophies.json` — البطولات مع فصل الدوري التصنيفي عن الدوري الممتاز/المحترفين
- `fixtures.json` — المباريات
- `history.json` — الخط الزمني

### ملاحظة توثيقية
تفصل الموسوعة لقب الدوري التصنيفي 1974/75 عن ألقاب الدوري الممتاز/المحترفين التسعة بدل جمعهما في رقم واحد بلا شرح.
